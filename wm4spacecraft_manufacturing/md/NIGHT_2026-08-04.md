## 1. shim 버그가 오라클의 완주를 통째로 죽이고 있었다 — **오늘 밤 최대 발견**

### 증상
`oracle/out/rb_core30/ep_s301.err` (DS_LOG=info): 팀 교착 알람 **499회** 발화 →
`ReformTeam` 제안 **0건** → 복구 **0건**. 그 판들은 전부 완주 실패.

### 원인
`CB.maybe_emit_reform_ood!` 는 `push_ood!`(respec 큐)만 하고 **`record_ood_truth!` 를 하지 않는다.**
그래서 팀 교착 알람은 truth 로그에 없다. `ood_mdp_shim.event_context` 는 NL 매칭 실패 시
**`last(log)` 를 집었고**("newest truth even if NL differs"), 그 결과 알람이 직전 사건(ZoneTruth)의
종류를 뒤집어써 `:zone` 으로 분류됐다. 그러면 생성기 producer 의

```julia
ctx.type === :reform && return action_to_proposal(ctx, canonical_action(ctx))   # ← 못 탐
(String(ev) in EP_SCHED_NL[]) || return nothing                                 # → NOOP
```

CASCADE 규칙으로 흘러 **NOOP** 이 된다 = 자가복구가 한 번도 안 돈다.

### 수정
매칭 실패 시 `last(log)` 대신 **문자열로 분류**(`_ctx_from_keywords`). 예약 사건은
`record_ood_truth!` 가 같은 NL 을 남기므로 정상 경로는 안 깨진다.
회귀 검사 `oracle/test_relocate_build.jl` §7b 추가 — **40/40 PASS**.

| RelocateBuild | 123/313, 미완주 | 147/313, 미완주 |

알람 261 → **ReformTeam 제안 261 → ADMITTED 257**(전부 `force_snapped`).
**NOOP 팔 오염 없음 확인**: `RESTAGE-ALL` 0, `restaged` 0 (배경 복구가 구역 기하를 안 건드림).

* 신규 노브: `DEMO_SEED`, `DEMO_SPARES`, `zonecore` 케이스.
* **표현력 에스컬레이션** — surrogate 가 유효 매크로를 **표현조차 못 하면**(학습 근거 0) novelty 와
